# Glimpse Session Reader 使用说明

这是 V0.1 开发预览，包含本地阅读器和可切换引擎的 Agent。

1. 解压整个便携包，双击 `Glimpse.UI.exe`。保留同目录下的 `Worker` 文件夹。
2. 点击“选择区域”，在想阅读的内容上拖出矩形；按 Esc 取消选择。也可先新建会话，再移动默认取景框。
3. 在“OCR 语言”中选择已安装的语言。中英混合页面可尝试 `zh-Hans-CN`；识别质量取决于 Windows 语言包、字号和画面。
4. 点击“开始观察”。通过取景框内部直接点击、选择和滚动原应用。拖动上边框移动，拖动边角缩放。
5. 画面停止变化满 1 秒后开始 OCR。蓝色代表处理中；绿色代表稳定帧已处理并保存，不表示内容完整或识别完全准确。
6. “累计文本”包含跨屏去重后的内容。“快照 / 来源”保留最近 9 次有效观察及原始文字、位置、首次来源和观测次数。累计文本不会随旧快照淘汰。
7. 随时点击“暂停观察”或“关闭取景框”。重新打开应用后选择会话并点击“打开 / 恢复”；恢复后默认暂停，需再次开始观察。
8. “导出文本”导出当前打开会话的 Markdown；“删除”会永久删除选中的本机会话，操作前会确认。

从旧版升级时，先退出旧版再打开新版，不要用同一数据目录同时运行两个版本。新版会保留阅读记录并将数据库升级到 v2；之后请继续使用新版，旧版不会读取新版数据库。

Agent 使用：

1. 切到“Agent”，展开“引擎设置”，选择 DeepSeek、Xiaomi MiMo、自定义兼容 API 或 CodeBuddy CLI。
2. API 填写服务地址、模型和密钥，点击“保存并切换”。留空密钥保留旧值；“清除已保存密钥”明确删除旧值。密钥由 Windows 当前用户加密，不会回显。
3. CodeBuddy 使用本机已安装的 CLI。npm 安装会自动探测 JavaScript 入口和 node.exe；也可填写独立 exe。不要把带参数的整条命令填进路径。先“保存并切换”，再点击“登录 CodeBuddy…”→“启动登录终端”。点击终端后直接用键盘上下选择、Enter 确认、Tab、Esc 和文字输入。xterm.js 支持终端选中复制、Ctrl+Shift+C/V、粘贴、字体调整和窗口尺寸适配；完整验证链接也可单独复制或打开。浏览器中的账户验证由你完成，应用不处理密码。完成后关闭登录窗口；模型列表会自动刷新，也可点“刷新模型”。选择下拉列表中的模型 ID 或自行输入后保存，留空使用 CLI 默认模型。重新预览、生成确认认证有效。关闭登录窗口会结束其 CLI 进程；CodeBuddy 已保存的登录状态保留。终端内容和链接不写入会话记录，进程退出代码 0 不等于登录成功。交互终端依赖 Microsoft Edge WebView2 Runtime；未安装时会提示使用基本模式和运行时下载入口。
4. 选择“帮我评论 / 帮我回复 / 总结 / 给我建议”，或自由提问。点击“预览将发送的上下文”，检查来源、修订、遗漏警告和已过滤文字。
5. 确认后点击“生成”。只有这一步会调用所选引擎；不会发送截图。可取消调用；无效 JSON 会标为原始文字，不会假装成为有效卡片。
6. 点击卡片的“复制文字”，只复制所见文本；应用不会自动填入、发布或发送。每次生成结束后需重新预览，再发起下一次请求。
7. 保存设置会使旧预览失效。阅读产生新修订时，已预览内容保持不变；需要新记录请重新预览。重新打开会话可查看上次已保存的有效结果。

“自动 · 小字增强”会对较小文字尝试内存放大识别；也可切换“原始尺寸”或“固定 2 倍增强”。细小中文仍可能识别不准，放大原应用字体通常更有帮助。

快速滚过且没有停留的文字无法补回。低重叠后的遗漏警告只是推测；没有警告也不保证完整。页面切换、相似短评论和 OCR 错字可能保守保留重复或标为待确认。原始识别证据不会静默改写。

普通观察不保存截图、不上传文本、不操作其他应用。只有主动生成才向所选引擎提交已预览的上下文，敏感内容过滤不能保证识别全部秘密，请检查预览。OCR 和 Agent 结果保存在 `%LOCALAPPDATA%\Glimpse\sessions.db`；密钥不在 SQLite 内，而在同目录加密的引擎配置中。需要备份时先关闭 Glimpse，再复制整个数据文件夹；不要只复制正在使用的 WAL 数据库主文件。加密密钥与 Windows 用户绑定，换电脑后可能需要重新输入。

故障排查：

- 没有 OCR 语言：在 Windows 设置中安装需要的语言 OCR 功能后重启 Glimpse。应用不会替你更改系统设置。
- 图像持续变化：暂停动画，缩小选区；也可以手动刷新。刷新仍遵守 1 秒稳定等待。
- 截取错误：把取景框完全移回连接的屏幕，避免受保护的视频内容。无法排除自身窗口时应用会停止观察。
- Worker 中断：最多自动重启 3 次；已提交数据保留。恢复后重新打开会话并明确开始观察。
- CodeBuddy 提示认证失效：展开引擎设置，使用“登录 CodeBuddy…”交互终端重新验证；也可在自己的终端运行 `codebuddy` 并使用 `/login`。CLI 有时会在认证失败时仍返回退出代码 0，应用会单独识别这种情况，不会在普通错误提示中显示原始认证诊断或令牌。登录界面包含临时验证链接，请勿分享；CLI 版本差异或企业登录提示可能需要使用外部终端。
- 数据位置：默认在 LocalAppData。高级用户可在启动前设置 `GLIMPSE_DATA_DIR`；`GLIMPSE_OCR_LANGUAGE` 可指定本地 OCR 语言。

本机已登录 CodeBuddy CLI 已实测默认模型和 `mimo-v2.6-pro` 生成、取消、有效卡片复制与历史保存；模型发现读到 16 个可用模型。xterm/WebView2 的显示、输入、选中复制和尺寸适配有本机合成测试。自动化回归使用离线替身和本机模拟 API，不消耗真实模型额度；真实供应商测试仅按用户请求主动运行。其他未完成验收见仓库 `docs/VALIDATION.md`。这不是已完成的 V0.1 正式版。
